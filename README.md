# NODEX Backend

Submission-ready Express + SQLite backend for the existing NODEX frontend.

## Run

1. Put this `backend` folder beside the existing `smart city` frontend folder.
2. In PowerShell:
   `cd "C:\Users\kaviya\Documents\GitHub\smart city\backend"`
3. Run `npm install`.
4. Run `npm start`.
5. Open `http://localhost:5000`.

The backend automatically creates `nodex.db` and required tables.

## Connected endpoints

Health, Wi-Fi, POIs, hospitals, news, complaints, complaint status updates, profile, SOS, emergency, dead zones, dashboard, search and AI chat.

No frontend code changes are required.
